# 前端布局修复交付

用户确认本次问题属于“布局、样式或显示异常”。本轮阅读现有源码、前端测试报告和已保存的移动端截图，未启动服务、重新截图或执行测试、类型检查与构建。

## 修改范围

- 复核确认栏由底部粘性定位改为正常文档流，位于评分点和历史记录之后，避免遮挡原答案、引用或理由输入框。确认按钮不再悬浮常驻，需要滚动到页面末尾提交。
- 页头和工具栏允许换行；筛选控件按可用宽度布局，小屏单列；步骤标签在自身容器内横向滚动。表格仍保留自身横向滚动，不通过隐藏整个页面的溢出来掩盖内容。
- 卡片、网格和标题允许收缩，长标题、学号、提交版本及评分描述可换行；引用位置及按钮可分行显示。窄屏学号单独一行，减少与姓名挤压。
- 等级描述增加独立的布局容器，小屏占满第二行；修正准备页工具栏的重复内边距，长操作按钮支持换行。
- 登录页在 860px 及以下改为单列；短视口下侧栏可滚动，移动端使用动态视口高度。分数汇总保留三列，小屏缩小字号并将确认操作排在下方。

实现集中于 `frontend/src/styles.css` 和 `frontend/src/features/preparation/RubricEditor.tsx`。未改接口、评分、引用坐标、持久化状态或数据库。

## 交给用户的验收点

这些是待执行项目，不是通过记录。建议在 320、390、768、1024、1440px 宽度以及浏览器放大至 200% 时检查：

1. 登录页、批次列表、作业准备、复核页和导出页没有整个页面的横向滚动；宽表格和步骤标签能在各自容器内访问全部内容。
2. 复核长答案时，原文、选区、引用、理由输入框不会被确认栏遮挡；滚动到末尾后能看到三个分数和完整提交按钮。
3. 小屏填写等级分数、描述、来源编号时不出现重叠或裁切；长按钮文字完整，焦点可见。
4. 长中文/无空格英文作业名、长学号、长评分点描述、错误提示和并发冲突面板能换行；学生原文中的空白、换行不被修改。
5. 正常保存细则、复核及导出仍可操作；既有业务回归入口见 [浏览器回归说明](../frontend/e2e/README.md)。

没有为纯样式调整增加镜像 CSS 的单元测试。历史报告中的截图和 42/21 通过数不构成本轮修复后的验收结果。
