# Harness v5：结果引用、预算预留与后台子任务

日期：2026-10-22。本文记录代码实现、机制对照和真实 API 验收；回归总览见 [实施记录](IMPLEMENTATION_STATUS.md)。

本轮继续对照最初的 [架构设计](ARCHITECTURE_REVIEW.md)、[实施计划](IMPLEMENTATION_PLAN.md) 和 [Harness v4](HARNESS_V4_2026-10-22.md)，补齐大工具结果引用、输入及输出 token 预留、金额预算、模型可调用的后台子任务和显式汇合、固定 Hook 配置，以及可恢复的事件订阅。领域层仍拥有固定教学事实、权限和确认规则，Harness 负责执行、恢复和审计，模型只能提出待验收结果。

这些能力由本项目的 PostgreSQL 状态机实现。本轮仅只读分析本地 source-map 恢复参考树，没有运行参考工程或复制其实现，也不声称与 Claude Code 全量对等。新增备课场景用于验证内核复用，通过现有课程 API 使用，没有新增备课专页。

## 大结果引用与上下文恢复

`tool-result-references-v1` 只对固定策略中允许的工具生效。当前仅 `lesson-plan-research` 开放 `search_teaching_memory` 外置：规范 JSON 正文超过 4000 字符时保存完整结果，模型投影展示 256 字符预览、记录 ID、原调用 ID、工具名、字符数和内容哈希。原始 `run.messages` 和完整工具回执仍然保存；外置减少请求上下文，不代表减少数据库历史大小。

记录绑定教师、运行、工具调用和原参数哈希，同一运行与调用 ID 只能形成一个结果。数据库禁止原地修改或删除；回读还核验原始调用、成功回执、正文和哈希。持有记录 ID 不能读取其他运行或教师的数据。

`read_tool_result` 接收 `id`、`offset`、`limit`，按规范 JSON 的 Unicode 字符位置分页。当前策略每页最多 4000 字符，返回 `text`、`next_offset` 和 `complete`。它没有任意文件路径、URL 或跨运行检索参数。预览明确标识不完整，正文仍是参考数据，不能成为更高优先级指令。

评分题目、固定简报、草稿写入、错误结果和回读工具自身都不在外置白名单。不能通过模型请求开启新的外置工具。原有确定性压缩与语义摘要继续保护固定事实、近期交互、未完成工具组和调用配对；无法容纳受保护内容时明确停止。

上下文检查点另保存 `source_view`，包含保存时原始消息前缀的哈希和引用集合哈希。重启时从完整原始记录重新生成同一前缀的投影，再校验摘要检查点。改变原正文、参数、引用或检查点不会被当作正常恢复。摘要请求和接受检查点也经过预算控制，不会因引用已存在而跳过审计。

研究备课场景沿用已确认课程记忆的范围与有效性规则。草稿中的记忆 ID/hash 必须来自运行实际检索快照；这不能证明模型已经理解所有分页内容。提示要求按需回读正文，读取轨迹和引用是否充分仍需真实模型验收，不能把预览当完整材料。当前没有强制逐页阅读全部记录的协议。

## token、输出与金额预算

新 v5 策略固定 `token-cost-reservations-v1`、估算版本 `utf8-json-envelope-v1`、模型上下文窗口、价格来源与价格版本。输入估算使用完整请求 JSON 的 UTF-8 字节数及固定协议余量，包含工具 schema 与参数；它是保守工程估算，不是供应商 tokenizer，也不宣称对任意模型都可精确计算 token。

每次请求同时预留其 `max_tokens` 输出额度。压缩规划同时检查字符上限和“输入估算 + 最大输出”是否落在固定上下文窗口内；摘要请求也必须通过检查。`TA_DEEPSEEK_MAX_OUTPUT_TOKENS` 控制部署输出上限，教师请求不能通过工具参数提高它。

创建运行可设置 `max_total_tokens` 和 `max_cost_usd`，与原有模型调用数、工具调用数、字符数和期限限制同时生效。根任务与全部子孙共享预留额度：领取派发时持有根锁，预算记录、调用计数和 `model_dispatched` 在同一事务中提交。额度不足不调用供应商，事务回滚不会留下半次派发或多扣调用数。

供应商返回完整有效 usage 后，预留只允许结算一次。已知输入、输出和缓存分项用于计算实际 token 及固定价格下的金额；缺少缓存拆分时保留保守金额口径。若实际用量超过预留或整树限制，先保存实际用量，再停止任务树，不回滚已发生费用的证据。响应已返回但业务验收拒收时，失败路径仍保存已知 usage 和供应商标识。

超时、连接中断、进程退出或不完整 usage 不返还未知调用的预留。后续重试是另一次派发，使用新的额度；取消本地协程不能证明供应商未处理或未计费。`known_cost_usd` 是可按已知 usage 与固定计价规则计算的部分，`accounted_cost_usd` 还包含未结算预留和保守金额，都不是供应商账单。

部署可通过 `TA_DEEPSEEK_CONTEXT_WINDOW_TOKENS` 显式配置窗口；自定义价格需要成对配置 `TA_DEEPSEEK_INPUT_USD_PER_MILLION`、`TA_DEEPSEEK_OUTPUT_USD_PER_MILLION`，并提供 `TA_DEEPSEEK_PRICE_VERSION`、`TA_DEEPSEEK_PRICE_SOURCE`。缓存价格可选。已识别的官方模型使用代码中固定的价格快照，不能把它解释为实时价格查询。未知模型无价格时可限制 token，但拒绝金额上限；未知窗口的回退值标注为未验证，部署者应明确配置。

`GET /v1/agent-runs/{run_id}/budget` 返回根任务整树汇总：`reported_tokens`、`reserved_tokens`、`accounted_tokens`、`known_cost_usd`、`reserved_cost_usd`、`accounted_cost_usd`、`unpriced_calls`、`unsettled_calls` 与 `calls`。从子任务读取也返回所属根树的预算。旧策略没有预算记录时的零值不代表旧调用实际零消耗。

## 后台子任务与显式汇合

`lesson-plan-background` 的工具目录固定为读取简报、后台复核、查询子任务、汇合和保存草稿。`spawn_lesson_review` 只创建 `lesson-review` 子任务，立即返回 `child_run_id` 和 `scheduled`，父任务随后可以继续 `read_lesson_brief` 等独立工作。该演示任务只允许创建一个复核子任务，不开放模型自定义任务类型、工具目录或任务图。

`get_child_output` 非阻塞返回 `not_ready`、`success` 或 `failed`，并附真实持久运行状态。仅终态成功且产物通过范围、类型和哈希校验时返回正文与引用。运行中快照不冒充完成输出，错误与取消不能冒充成功。

`join_child` 接收同一父任务拥有的子任务 ID。若结果未就绪，保存原 join 调用与 spawn 调用的绑定，转入 `waiting_children` 并释放租约；Worker 只检查数据库状态，不通过重复模型调用等待。子任务终态后，原 join 调用得到唯一配对回执，经过 typed result、Hook 和任务验收后恢复父任务，接收结果不再扣一次工具额度。若结果已经就绪，则立即返回同样的校验结果。

join 没有模型指定的独立无限等待或自定义超时参数；父子任务仍受既定期限、整树预算和取消规则约束。数据库调度扫描会继续运行，等待本身不增加模型调用。模型若主动重复状态查询仍消耗普通工具预算；系统提示要求 `not_ready` 后使用 join。

父子任务必须保持同一教师、课程输入、根树、固定允许边和深度。父任务取消、失败或预算终止会处理未结束后代；旧 Worker 由 epoch 和租约阻止回写。子任务身份或产物损坏会形成失败回执，不触发无界重新派发。进程重启从持久 join 状态恢复。

最终方案必须显式 join 成功，原样保留子任务的复核正文及 `child_run_id`、`artifact_id`、`content_hash`，保存前再次核对实际子产物。复核内容是针对固定简报的检查要点，不是已经审核最终方案，更不是教师批准。根任务保存后进入 `waiting_teacher`，仍需教师单独确认。

## 固定 Hook 与可恢复事件订阅

v5 将 Hook 快照写入 manifest，并参与 profile 哈希。当前代码注册 `deny-tools` 实现版本 `1`，配置为 `denied_tools` 和 `block_stop`；部署参数为 `TA_HARNESS_HOOK_ID`、JSON 格式的 `TA_HARNESS_HOOK_CONFIG`。例如 `{"denied_tools":["propose_rubric"],"block_stop":false}`。扩展只能由应用代码注册，模型不能传入模块路径、Shell 命令、URL 或任意执行器。

Worker 领取及恢复时校验 ID、实现版本、配置 schema 和哈希。更换部署配置会形成新的 profile；旧运行不会静默获得新行为，需要仍提供原固定策略的 Worker 才能继续。v5 不接受构造器传入的任意 Hook 覆盖快照；旧协议保留原行为。Hook 只能增加拒绝，不能绕过课程授权、修改验证后的工具结果或把不存在的产物当成完成。

事件接口新增 `GET /v1/agent-runs/{run_id}/events/stream`。数据库事件表是事实来源；SSE 只提供有界回放，每页最多 100 条，序号递增。游标使用 `after` 或 `Last-Event-ID: <run_id>:<sequence>`，两者同时存在时取较大序号，拒绝其他运行的游标。

连接默认持续 25 秒，`follow_seconds` 可为 0–60 秒。帧类型为 `agent_event`、`end`、`reconnect`、`error`，空闲时发送 heartbeat 注释。`waiting_teacher`、`completed`、`failed`、`cancelled` 在已有事件发送完后结束；输入等待不被误判为终态。客户端根据已接收序号去重并重连，不能宣称网络交付恰好一次。

开启响应前及每次数据库分页都检查教师身份、课程权限和令牌是否仍有效。中途撤权发送错误帧并断开。连接不占用长事务，也不触发模型调用。现有 `AgentPanel` 仍使用有限轮询；后端 SSE 入口已实现不等于前端已改成流订阅。

## API 使用示例

以下都是接口形状示例，不会执行。替换 `{course_id}`、`{run_id}` 与哈希/token 为响应值。请求使用现有 `Authorization: Bearer <token>`；每个 POST 带独立 `Idempotency-Key`，重试同一操作保留原 key 和正文。开发 Bearer 身份机制仍不等于完整生产组织身份系统。

先查询可用的任务配置，明确选择 fake 或真实适配器：

```http
GET /v1/agent-profiles?task_type=lesson-plan-research
GET /v1/agent-profiles?task_type=lesson-plan-background
```

研究备课读取已确认课程记忆；记忆创建和确认接口见 [v4 API 示例](HARNESS_V4_2026-10-22.md#api-示例)。创建运行：

```http
POST /v1/courses/{course_id}/lesson-agent-runs
Content-Type: application/json

{
  "agent_profile": "fake-research-lesson-agent-v1",
  "instructions": "查阅已确认课程资料，分页读取需要的正文；缺少必要信息时向我提问，然后起草方案。",
  "brief": {
    "topic": "资料来源与可追溯性",
    "objectives": ["说明为什么要保留材料来源"],
    "duration_minutes": 20
  },
  "max_model_calls": 12,
  "max_tool_calls": 24,
  "max_total_tokens": 200000,
  "max_cost_usd": "0.5"
}
```

真实适配器别名为 `deepseek-research-lesson-agent-v1`，仅在 profile 显示 ready 且明确需要真实模型时选择。`research` 名称表示查阅本课程已确认记录，不表示联网搜索、外部论文检索或自动导入材料。示例额度只是可配置上限，不是调用成本承诺。

后台复核使用同一路径和简报契约，将 `agent_profile` 改为 `fake-background-lesson-agent-v1` 或显式的 `deepseek-background-lesson-agent-v1`；例如 `instructions` 为“后台生成简报复核要点，同时完成独立准备，显式汇合后起草带复核来源的方案”。不要给该任务要求 `ask_teacher` 或记忆检索，它们不在此固定工具目录中。research 和 background 两类任务默认调用上限为 12 次模型、24 次工具；调用数包含整树和摘要开销，仍可能因实际轨迹而不足。

运行部署的 Worker，例如在项目根目录执行：

```powershell
uv run --frozen teaching-assistant harness-worker --drain --concurrency 2
```

`--drain` 会处理当前可领取工作和动态子树，但不会常驻等待教师回答；回答后需要再次运行或使用常驻 Worker。查询运行、树、预算、检查点与产物：

```http
GET /v1/agent-runs/{run_id}
GET /v1/agent-runs/{run_id}/children
GET /v1/agent-runs/{run_id}/budget
GET /v1/agent-runs/{run_id}/context-checkpoints
GET /v1/agent-runs/{run_id}/artifact
```

若 research 运行出现 `wait.question`，依据原问题提交真实教师回答：

```http
POST /v1/agent-runs/{run_id}/wake
Content-Type: application/json

{"wait_token":"<wait.token>","response":"先安排三分钟独立思考，再开展同伴讨论。"}
```

后台 spawn、输出查询和 join 是模型工具，不是额外的公开 POST 路由；调用方通过运行详情、children 和事件观察它们。人工取消继续使用 `/cancel`。教师阅读最终产物后通过 `/confirm` 提交 `{"content_hash":"<artifact.content_hash>"}`，不会由模型或子任务自动确认。

事件订阅与断线重连示例：

```http
GET /v1/agent-runs/{run_id}/events/stream?after=0&follow_seconds=25
Accept: text/event-stream
Authorization: Bearer <token>
```

```http
GET /v1/agent-runs/{run_id}/events/stream?follow_seconds=25
Accept: text/event-stream
Authorization: Bearer <token>
Last-Event-ID: {run_id}:17
```

收到 `reconnect` 后使用实际最后序号重连；普通分页 `/events?after=<sequence>&limit=100` 继续可用。需要 Bearer 请求头的浏览器调用可使用支持自定义请求头的流式客户端，不应把令牌放到 URL 中。

## 迁移与兼容性

当前代码要求数据库迁移到 **0012**：

| 迁移 | 内容 | 降级约束 |
| --- | --- | --- |
| 0011 | 新增 `agent_tool_results`，绑定运行/教师/调用，唯一结果回执、范围检查及不可变触发器 | 存在结果历史时拒绝降级 |
| 0012 | 新增 `agent_model_reservations`，绑定根树和 `model_dispatched` 事件，保存固定请求/价格与一次结算 | 存在任何预留历史（包括未知调用）时拒绝降级 |

后台 join 使用已有 `AgentRun` 状态、`task_state`、事件与租约；Hook 快照保存在 manifest；SSE 复用事件表。它们没有独立新表。部署按既有备份与迁移流程执行 `uv run --frozen alembic upgrade head`，再启动匹配版本 API 和 Worker。本文件不代表业务库已经升级；实际库版本由最终验收记录说明。

v1–v4 manifest 构造保留旧字段与旧工具/提示哈希，旧运行不会自动升级、增加工具或产生 v5 token 预留。新配置参与 v5 profile ID；部署配置改变后恢复旧运行必须提供匹配策略，不能改写历史 manifest 迁就当前配置。代码兼容旧运行不等于新版 Worker 可以在旧数据库 schema 上运行。
